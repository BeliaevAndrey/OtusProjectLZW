## OTUS проектная работа
### Реализация архиватора на основе алгоритма LZW

* /single_file -- черновой вариант
* /modular -- версия с разделением на модули, сжатые данные сохраняются из типа int, в качестве словаря используеься std::map
* /modular_v2 -- версия с разделением на модули, сжатые данные сохраняются из типа short, в качестве словаря используеься std::map
* /modular_v3 -- версия с разделением на модули, сжатые данные сохраняются из типа short, в качестве словаря используеься std::unordered_map
* /TestData -- данные использовавшиеся для тестрования (видео-файлы не включены)
